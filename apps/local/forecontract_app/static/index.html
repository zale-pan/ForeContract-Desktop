                                      外观与编辑（偏好保存在本机浏览器）

                                      Diff 展示与证据抽屉说明：运行文件差异（Run Diff）、工作区只读文件与本机 Git 差异（暂存区 / 工作树）均通过会话工作台右侧「运行详情」证据抽屉展示，可直接在运行卡点击「查看 Diff」或顶部「展开详情」打开，并支持将选定差异块带入只读对话。

                                      桌面与托盘（Windows 桌面外壳只读说明）

                                      当前桌面外壳由 Electron 本地宿主驱动，窗口关闭与系统托盘策略为固定受控行为（只读展示，无前端可写开关）。
                                      • 关窗收起至系统托盘：点击主窗口右上角关闭按钮时，窗口隐藏并收起至 Windows 系统托盘，后台本地 Python 宿主与活动运行继续保持连接，不会中断正在执行的任务。
                                      • 通过托盘恢复或退出：点击系统托盘图标或托盘菜单「打开 ForeContract」可恢复当前主窗口与同一会话；完全退出应用须通过系统托盘菜单「退出 ForeContract」（若有活动运行将先提示确认）。
                                      • 单实例与同源边界：同一数据根保持单实例锁；桌面渲染进程仅允许访问本次宿主绑定的 127.0.0.1 loopback 源。

                                      模型与连接（只读宿主状态）

                                      状态来源：本机宿主启动配置与 /api/v1/health 实时读回；API 凭据仅由宿主进程持有，不进入前端页面或浏览器偏好存储，创建会话后历史会话绑定模型保持不变。

                                      审批与命令（真实授权边界）

                                      • 目录范围：受控项目与本机已有项目严格隔离；已有项目从只读起步，写入须先批准精确路径与操作。
                                      • 逐提案审批：修改范围、验证计划、本机命令及 MCP 连接/调用分别独立审批，待审批项内联展示在会话工作台与审批收件箱。
                                      • 受信任本机执行：命令批准时须显式勾选 trusted_local_execution 表示受信任本机执行，而非 OS 沙箱隔离。

                                      会话约束（按当前会话持久化）

                                      当前约束修订：rev=0 history_cursor=0 无未保存草稿（草稿未保存，刷新会丢失）

                                      存储与保留（SQLite 只读展示）

                                      • 真实用量：数据来源于当前会话 /api/v1/sessions/{sid}/context 的 storage_used_bytes（SQLite sessions.sqlite3 实际字节数），仅作只读展示。
                                      • 数据保留策略：用户项目与会话持久数据保存在本机 SQLite，与开发验收临时目录严格分离，前端不提供后台静默回收操作。
